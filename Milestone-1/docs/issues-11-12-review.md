# Sprint 2 — Issues #11 and #12: Review Materials

## Issue #11 — Object-oriented design decisions

The team's design rationale is documented in [Issue #11](https://github.com/sa2305215/PearlMart-MileStone1/issues/11), including:

- Responsibility assignment among InventoryService, Item, InventoryTransaction, and supplier-order classes.
- Encapsulation using visibility modifiers and controlled update methods.
- Abstraction through InventoryService and Sale operations.
- Modularity across inventory and supplier-order classes.
- Inheritance, composition, and association relationships.

The reviewer should read the full original explanation in Issue #11 and compare it with the final class diagram.
