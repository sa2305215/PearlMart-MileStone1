# PearlMart Context DFD

## Main Process

The main process is the PearlMart Inventory Management System.

## External Entities

- Supplier
- Customer
- Salesperson
- Store Manager

## Main Data Flows

| External Entity | Data Flow | System |
|---|---|---|
| Supplier | Supplier orders and supply information | PearlMart Inventory Management System |
| Customer | Sales transaction details and replacement requests | PearlMart Inventory Management System |
| Salesperson | Sales transaction details | PearlMart Inventory Management System |
| Store Manager | Inventory update requests and inventory information | PearlMart Inventory Management System |

## Review Notes

The context diagram represents the complete system as one main process. External entities are kept outside the system boundary, and the data flows show the main information exchanged with the system.
